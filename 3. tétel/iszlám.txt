Az iszlám kialakulása {
    -----------------------------------------------------------------
    | Előzmény:                                                     |
    | az arab félszigeten születik a vallás                         |
    | -> az északi területen haladnak át a karavánutak              |
    | -> a kereskedők különböző vallások területén haladnak át      |
    |                                                               |
    | arab (heduin) törzsek a vézért harcolnak egymással            |
    | -> egyesíteni kell a törzseket                                |
    -----------------------------------------------------------------
    Mohamed:
        -tevehajcsárból lett kereskedő
        -álmában megszólítja Gábriel arkangyal és új vallás alapítására kéri
        -Mekka piacterein prédikált, sok követőre lelt a szegények között
        -ellenségei elől Medinába menekül 622-ben (hidzsra) -> vallás kezdete
    => vallás nagy léptékű terjedése
}
A vallás {
    Iszlám:
        -iszlám szó jelentése: belenyugvás
        -monoteista vallás (egyistenhit)
        -ábrahámi vallások/"Könyv vallásai"-nak egyike
        -istene: Allah (jelentése: "az Isten"): központi mindenható lény
        -Mohamed Allah prófétája
        -szent könyve: Korán (114 fejezet)
        -5 pillér (hitvallás):
            -"Egy az isten, Allah és Mohamed az ő prófétája"
            -alamizsna a szegényeknek
            -Ramadan havi böjt
            -egyszer a Kába kőhöz zarándokolni
            -napi 5 ima Mekka felé fordulva
        -további parancsolatok:
            -nincs disznóevés
            -nincs alkohol
            -szent háború (dzsihád) -> vallás terjesztése
    => összefogja a törzseket -> terjeszkedés indul
    -> Észak-Afrika, Gibraltár
    -> Martell Károly megállítja őket 732-ben Poitiers-nél
    -> központ: Bagdad és Damaszkusz
}
Jellemzők {
    -kalifa: vallási és állami vezető
    -bíráskodás alapja a Korán
    -elterjed az arab kultúra1
}

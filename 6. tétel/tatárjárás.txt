IV. Béla tatárjárás előtti politikája {
    -------------------------------------------------------
    | Előzmény:                                           |
    | II. András halála után fia, IV. Béla került trónra  |
    -------------------------------------------------------
    Béla szakítani próbált apja politikájával (ellenezte a birtokadományozást)
    -> erőszakos birtokvisszavételbe kezd
    -> elveszíti a bárók bizalmát, nem adnak neki több katonát

    Julianus barát hírt hoz a tatárokról (mongolok)
    -> Béla behívja és letelepíti a hadra fogható kunokat
    -> DE: a bárók megölik a kun kánt, Kötönyt
    => kunok kivonulnak -> nincs hadsereg

    Kijev elesése után ébred rá igazán a veszélyre, de a bárók továbbra is bizalmatlanok a királlyal szemben
}
A tatárjárás (1241-1242) {
    a Vereckei-hágón keresztül érkeznek a Kárpát medencébe a tatárok Batu kán vezetésével
    -> elsöprik Tomaj Dénes nádor hadát
    => szabad út az ország belsejébe

    döntő ütközet: Muhi-csata (1241 ápr. 12)
    -> hatalmas magyar vereség
    -> IV. Béla nyugat felé menekül (Dalmáciában, Trau várában vészelte át a tatárjárást)
    => a tatárok feldúlják a Dunántúlt, a tél beállta után átkelnek a Dunán de nem bírnak a várakkal

    1242-ben meghal a tatár nagykán
    => a tatárok elhagyják Magyarországot
    => IV. Béla visszatér Magyarországra
}
IV. Béla tatárjárás utáni politikája {
    FORDULAT: Béla szakít korábbi politikájával
    -> birtokadományozásba kezd, de csak hűbérbe és várépítési kötelezettséggel ad földbirtokot
    -> a városoknak falat kell építeni
    -> megerősíti a köznemesek Aranybullában szereplő szabadságjogait

    betelepítés: szlovákok, románok, kunok
    -> beolvadnak a magyarságba
    => IV. Béla: "második honalapító"
}

IV. Béla tatárjárás előtti politikája {
    -------------------------------------------------------
    | Előzmény:                                           |
    | II. András halála után fia, IV. Béla került trónra  |
    -------------------------------------------------------
    Béla szakítani próbált apja politikájával (ellenezte a birtokadományozást)
    -> erőszakos birtokvisszavételbe kezdett
    -> elveszítette a bárók bizalmát, nem adtak neki több katonát

    Julianus barát hírt hozott a tatárokról (mongolok)
    -> Béla behívta és letelepítette a hadra fogható kunokat
    -> DE: a bárók megölték a kun kánt, Kötönyt
    => kunok kivonultak -> nincs hadsereg

    Béla Kijev elesése után ébredt rá igazán a tatár veszélyre
    -> DE: a bárók továbbra is bizalmatlanok voltak a királlyal szemben
}
A tatárjárás (1241-1242) {
    a tatárok a Vereckei-hágón keresztül érkeztek a Kárpát medencébe Batu kán vezetésével
    -> elsöpörték Tomaj Dénes nádor ottani hadát
    => szabad út az ország belsejébe

    döntő ütközet: Muhi-csata (1241 ápr. 12)
    -> hatalmas magyar vereség
    -> IV. Béla nyugat felé menekült (Dalmáciában, Trau várában vészelte át a tatárjárást)
    => a tatárok feldúlták a Dunántúlt, a tél beállta után átkeltek a Dunán de nem bírtak az ottani várakkal

    1242-ben meghalt a tatár nagykán
    => a tatárok elhagyták Magyarországot
    => IV. Béla visszatért Magyarországra
}
IV. Béla tatárjárás utáni politikája {
    FORDULAT: Béla szakított korábbi politikájával
    -> birtokadományozásba kezdett, de csak hűbérbe és várépítési kötelezettséggel adott földbirtokot
    -> a városoknak falat kellett építeni
    -> megerősítette a köznemesek Aranybullában szereplő szabadságjogait

    betelepítés: szlovákok, románok, kunok
    -> beolvadtak a magyarságba
    => IV. Béla: "második honalapító"
}

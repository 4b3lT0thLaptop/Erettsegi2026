Magyarság őstörténete {
    A magyarságnak nincs egységesen elfogadott őstörténete
    -> több eredettörténet verseng egymással

    segédtudományok alapján következtethetünk a magyarság eredetére:
        -középkori krónikák -> hun-magyar rokonság
        -archeogenetika     -> ázsiai eredet
        -nyelvészet         -> finnugor eredet
        -régészet           -> türk eredet
    => a finnugor eredettörténet a legelfogadottab nézet

    Magyarság:
        -lovas, nomád nép
        -álattenyésztéssel foglalkoztak
        -jurtákban éltek
        -a legelők után vándoroltak
}
A vándorlás állomásai {
    Magna Hungaria (Kr.e. 1. század):
        -Urál déli lejtőjének nyugati oldala
        -a mai Baskíria területe
        -laza törzsszövetségben éltek
    Levédia (750):
        -Fekete-tenger északi része
        -a Kazár Birodalom fennhatósága alá került a magyarság zsoldosként
        -átvették tőlük:
            -földművelést
            -rovásírást
            -kettős fejedelemség rendszerét:
                -Kende: szellemi vezető
                -Gyula: tényleges vezető
    Etelköz (830):
        -a Dnyeper és a Duna között
        -velük tartott 3 kazár törzs
        -itt vérszerződést kötöttek a Kárpát-medence elfoglalására
        -Álmost fejedelemmé választották
    => 895 honfoglalás
}
Honfoglalás {
    2 elmélet a honfoglalásra:
        -tervszerű honfoglalás
        -kényszerű honfoglalás: besenyők elől menekültek

    a Kárpát medencében avarok és szlávok laktak
    -> magyarok legyőzték az itt élőket
    -> kalandozásba fogtak
    => sikerek (Itália, Bizánc)
    -> kiismerték a harcmodorukat
    -> két vereség a keleti frankoktól:
        -Merseburg (933)
        -Augsburg (955)
    => a magyarok végleg letelepedtek a Kárpát medencében
}
